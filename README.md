# anaclumos/homebrew-tap

Homebrew casks by anaclumos.

```sh
brew tap anaclumos/tap
brew trust --tap anaclumos/tap
brew install --cask anaclumos/tap/anaclast
brew install --cask anaclumos/tap/font-sunghyun-sans
```

| Cask | Installs |
|---|---|
| `anaclast` | Anaclast, a keyboard layer, window tiler, launcher and clipboard history for macOS 27 |
| `font-sunghyun-sans` | Sunghyun Sans, for Latin, Cyrillic, Greek and Vietnamese |
| `font-sunghyun-sans-kr` | Sunghyun Sans KR, for Korean and Latin |
| `font-sunghyun-sans-kr-hanja` | Sunghyun Sans KR Hanja, for Korean with Hanja and Latin |
| `font-sunghyun-sans-jp` | Sunghyun Sans JP, for Japanese and Latin |
| `font-sunghyun-sans-disambiguated` | Sunghyun Sans Disambiguated, for Korean, Japanese and Latin with disambiguated glyphs |

The Sunghyun Sans casks install the static OTF files of each family from its [GitHub release](https://github.com/anaclumos/sunghyun-sans/releases/latest).
